# Documentation
This sub-directory collects a set of documentations, which are all related to the $\texttt{AthenaK}$ code and analysis of $\texttt{AthenaK}$ data. Currently documented are:
- Ejecta and neutrino analysis (`ejecta_neutrinos`): describes the analysis scripts in KPlot, which data is needed from $\texttt{AthenaK}$ and what outputs are created
- Postprocessing specifications (`postprocessing`): collects some $\texttt{AthenaK}$ variable conventions and lists computations of derived variables that can be computed in post-processing, such as the Poynting flux etc.
- $\texttt{AthenaK}$ output disk usage estimates (`output_analysis`): collects disk usage estimates for specific analysis such as ejecta, neutrinos, tracers etc. based on the number of needed files and output frequency
- $\texttt{AthenaK}$'s M1 coupling with $\texttt{BNS-nurates}$ (`M1_nurates`): describes how the M1 scheme works and how it couples to the opacity library $\texttt{BNS-nurates}$
- Driftcontrol treatment (`driftcontrol`): describes the different driftcontrol algorithms to pull back drifting remnants
